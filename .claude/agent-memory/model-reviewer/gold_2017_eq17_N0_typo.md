Gold 2017 (`doc-reference/fragmentation/fragment-size-distribution-conwep/
1-s2.0-S221491471730079X-main.md`) defines `N₀ = M/2μ` at line 54 and in
eq. (1)'s prose, then restates it as `N_0j = m_j/μ_j` (no factor of 2) in
eq. (17). These are inconsistent within the same paper. Confirmed by direct
read: the factor-of-2 version (line 54) is the one to follow — `μ` is
defined throughout as *half* the mean fragment mass, so `N₀ = M/2μ` is the
only self-consistent reading. Treat eq. (17) as a typo if a future pass
cites it directly, rather than re-deriving which convention is "right."
