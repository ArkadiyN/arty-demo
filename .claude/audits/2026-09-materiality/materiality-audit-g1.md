## Patterns

- **B waste is dominated by doc-vs-doc / doc-vs-live-code staleness, and its cost is re-flagging, not fixing.** In wdss1 the same stale-cross-reference class was re-found and re-deferred in 5+ passes; frag-3d's 578/1578 and wdss1's I1 table cell each consumed a full fix + re-review with zero shipped delta. A tolerance gate keyed on *shipped/computed outputs* would have filtered all of these safely; the ones marked Blocking got there via the "published wrongness is never deferrable" rule, not via magnitude. A cheaper instrument than a cycle would have been a grep-completeness check at fix time.
- **What separated C from B before the outcome: the finding was about an *input's identity, basis, or regime*, not about an output delta — and the reviewer's impact statement was conditional.** C rows read like "zero *if* reading X is right" (F1 carbon ranking → headline doubled), "this band is model-vs-model, not data" (test re-base), "row fails the source's own closure" (803→779, Mott 0.45 %C row → γ′ re-anchor), "past the thin-plate regime" (t_bu/x̄). B rows had a reviewer-stated bound that held *under every reading* (F5: every plausible alternative only widens the margin; J1: γ is sourced independently, so no number can move) or the wrong value was a printed copy of something the code computes live.
- **A headline-number gate misses flips in secondary claims.** The Mott re-extraction left adopted γ = 47 unchanged by coincidence (0% delta) while reversing the direction of a shipped uncertainty bound (lower → upper, −47/−50% → −31/−36%); F14 and H6 were zero-output staleness that were the channel for wrong numbers into published pages. A gate must test *sign/direction of any shipped claim*, not just the magnitude of the parameter.
- **Conversely, "trend reverses" over-triggered on a sub-tolerance quantity.** H5's R50 reversal was +2.5% → −1.2% on ~46 m (both inside any reasonable tolerance); the Blocking was justified only by the co-located N0 contrast (−38.5% → −13.8%). A declared tolerance would have correctly split those halves.
- **Reviewer "Impact: zero" was reliable for comment/doc findings and unreliable for provenance-of-input findings.** Every comment/doc "zero" in these files held; F1's "zero under the plausible reading" and the re-extraction's "γ unchanged" both concealed decision-relevant changes. A safe gate would exempt closure-invariant failures, basis/regime/criterion questions, and conditional-impact findings, and apply the numeric tolerance only to findings whose delta the reviewer can bound unconditionally.
