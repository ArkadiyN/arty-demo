## Background

The M49A2 is a 60mm high-explosive mortar shell used by the US military in WW2 and post-war periods. This ordnance drawing is the primary manufacturing document that calls out which steel grade (WDSS-family or equivalent) was actually specified for production.

**Context:** The project's existing `ammunition-series-6-wdss-specs/` documents the WDSS 1–7 standardized grades as of 17 February 1953. For 60mm mortar shells, WDSS 1 (0.14–0.20% C, ductile) and WDSS 2 (0.28–0.34% C, balanced) are listed as applicable. This drawing should identify which of these (or another grade) was actually called out.
